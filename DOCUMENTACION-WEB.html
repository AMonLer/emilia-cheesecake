1. RESUMEN DEL PROYECTO

Emilia Cheesecake es una tienda online de cheesecakes artesanales con sede en Zürich, Suiza. La web está desarrollada con Next.js 14 y permite a los clientes ver productos, realizar pedidos y pagar online.

Características principales:

  • Catálogo de 5 sabores de cheesecake
  • Carrito de compras con persistencia
  • Checkout con Stripe (pagos con tarjeta, Apple Pay, TWINT)
  • Emails transaccionales con Resend
  • Notificaciones por Telegram
  • Newsletter con suscripción
  • Formulario de contacto
  • Diseño responsive y optimizado

9. FLUJO DE COMPRA

  1. Usuario navega → Página de inicio o productos
  2. Selecciona producto → Elige tamaño y cantidad
  3. Añade al carrito → Se guarda en localStorage
  4. Va al checkout → Introduce datos de entrega
  5. Selecciona fecha → Calendario con fechas disponibles
  6. Paga con Stripe → Tarjeta, Apple Pay o TWINT
  7. Webhook confirma → Stripe notifica el pago
  8. Se envían emails → Confirmación al cliente + notificación admin
  9. Notificación Telegram → Admin recibe alerta
  10. Página de éxito → Cliente ve confirmación

10. INTEGRACIONES EXTERNAS

Stripe (Pagos)

  • Dashboard: dashboard.stripe.com
  • Webhook endpoint: /api/webhooks/stripe
  • Métodos: Card, Apple Pay, Google Pay, TWINT

Resend (Emails)

  • Dashboard: resend.com
  • Dominio verificado: emilialab.com
  • Plantillas en: /emails/

Telegram (Notificaciones)

  • Bot para notificaciones de pedidos
  • Configurado con TELEGRAM_BOT_TOKEN y TELEGRAM_CHAT_ID

Vercel (Hosting)

  • Despliegue automático desde Git
  • Variables de entorno en dashboard de Vercel
